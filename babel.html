babel

Babel displays 16 public Steam profile pictures in a four-column, four-row grid. Each picture links to another generated Babel page. Profile pictures are retrieved from the avatar element on public Steam Community profile pages without a Steam Web API key.

Page generation

Each picture links to one of seven generated destinations distributed across the project's seven domains in a random order. Destinations use a random 63-character alphanumeric subdomain and a random alphanumeric path after /babel/. Each complete URL occupies a 16 KB budget.

Following a link generates another page. A deterministic generator is seeded with a SHA-256 hash of the complete URL. The same URL produces the same candidate accounts and destinations. Account IDs are sampled from 1 through 4,294,967,295 and converted to SteamID64 for lookup. Unavailable profiles are skipped with a bounded number of attempts. Lookups are cached for one day, and pictures may change when their owners update them. Failed lookups leave an empty tile.

Search indexing

This description is the stable project page. Generated avatar pages carry search-indexing and link-following exclusion directives.
