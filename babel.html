avatar-rng

avatar-rng displays 16 public Steam profile pictures in a four-column, four-row grid. Each picture opens its Steam profile in a new tab. Profile pictures are retrieved from the avatar element on public Steam Community profile pages without a Steam Web API key.

Page generation

A deterministic generator is seeded with a SHA-256 hash of the complete URL. The same URL produces the same account selections. SteamID64 values are generated by adding an offset from 0 through 4,294,967,294 to 76,561,197,960,265,729. Each tile looks up exactly one account; missing profiles leave an empty tile. Cached pictures appear first. New profile lookups run sequentially, at most once per second, while image downloads overlap. Server-cached profile results do not wait for this interval. The new button opens a freshly seeded grid. Successful lookups are cached for seven days and missing profiles for one day. Loading stops when Steam blocks or rate-limits a request, and the serving edge pauses new lookups for at least ten minutes. Every attempted account ID is recorded in the browser cache so it is not looked up again. Successful pictures are saved with their account IDs and reused locally on later visits; unsuccessful attempts remain blank. Browser storage is specific to the current site and can be cleared or evicted by the browser.
