BIP39

Bitcoin Improvement Proposal 39 (BIP39) describes a method for representing binary entropy as a sequence of words. Software can use the resulting mnemonic, together with an optional passphrase, to derive a seed for a deterministic wallet.

Word list and checksum

The English word list contains 2,048 entries. Each word represents 11 bits. A 24-word mnemonic encodes 256 bits of entropy and an eight-bit checksum derived from SHA-256, producing 264 bits in total.

Browser implementation

The BIP39 generator obtains 32 random bytes through the browser's Web Crypto API and computes the checksum locally. It displays the resulting words in four columns and six rows. Copying selected words produces text with a single space between words.

Reloading the page generates a new mnemonic.
